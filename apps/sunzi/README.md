# Sunzi

Sunzi's *Art of War* for skilful living, kept simple: the rendition, the tales, and what each principle means for daily life.

- **Chapters:** all 13, 152 verses, in an original English rendering. Under each verse, a short note "For daily living" and a link to any tale that illustrates it. Each chapter ends with its five tales.
- **Tales:** 65 stories from history and legend across China, Japan, India, Persia, the Islamic world, Africa, Europe and the Americas, retold in new words, five per chapter. Each tale page has the story, then "What it teaches" (tap to reveal) and a question "For your life".
- Day and Night themes, chosen for clear contrast (all text ≥ 4.5:1); text size; install prompt; offline.
- Fonts: Cinzel and Cormorant Garamond (SIL OFL).
