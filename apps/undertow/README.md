# Undertow

A private guide for the owner. Unlisted (not in the studio index or README table; noindex). All content is
AES-256-GCM encrypted in `data/undertow.enc.json` (key from the owner's 8-digit passcode via PBKDF2-SHA256, unlocked in
the app by `lib/vault.js`); the plain source is kept out of the repo. Notes stay on the owner's phone.
