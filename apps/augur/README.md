# Augur

A private guide for the owner. Unlisted (not in the studio index or README table; noindex). All content is
AES-256-GCM encrypted in `data/augur.enc.json` (key from the owner's 8-digit passcode via PBKDF2-SHA256, unlocked in
the app by `lib/vault.js`, with an optional quick PIN per phone); the plain source is kept out of the repo.

Twenty-four principles in five books on attention and cold reading (observe and listen well, then deliver a reading:
Barnum statements, the rainbow ruse, soft fishing, the great themes, many outs, the small detail, the delivery, and the
ethics). Same format as Allure and Anchor: motto, essence, four techniques, two true tales, the deeper why,
practices, the shadow and the owner's notes. Fonts: Cormorant Garamond (SIL OFL).
